# Pothik: Bangladesh Tourism Information and Tour Planning Portal

A dynamic, database-driven web application for tourists visiting Bangladesh.
Course: CIS324 (Web Engineering) | Student ID: 241-16-005 | Section: 19-A

## Features
- Destination guides for 10 popular spots
- Travel directory and emergency/essentials hub
- Budget calculator and packing checklist
- Trip planner
- User registration and login
- Tour package booking with admin approval
- Reviews and ratings

## Tech Stack
PHP (plain), MySQL, Tailwind CSS, JavaScript

## Setup
1. Install XAMPP and start Apache + MySQL
2. Clone this repo into `C:\xampp\htdocs\pothik`
3. Create a database named `pothik_db` in phpMyAdmin
4. Import `database/pothik_db.sql` (will be added later)
5. Open `http://localhost/pothik`
